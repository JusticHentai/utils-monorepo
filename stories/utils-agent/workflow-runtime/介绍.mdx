# workflow-runtime

`utils-agent` 提供通用 LLM agent 的基础运行框架。当前实现已经拆成 `workflow` 和 `runtime` 两层：

- `workflow` 定义执行步骤和步骤跳转。
- `runtime` 持有运行状态，负责调用 provider、执行 capability、写入 memory、应用 policy。
- `agent` 是对外门面，默认挂载内置 workflow。

## 具体实现原理

1. **文件职责**: `workflow/defaultWorkflow.ts` 定义默认流程，`runtime/AgentRuntime.ts` 执行具体节点逻辑，`runtime/executeWorkflow.ts` 负责步骤跳转。
2. **核心流程**: `prepare` 读取 memory 并拼装消息，`callModel` 调 provider，`handleTools` 执行 capability，`finalize` 写回 memory 并产出结果。
3. **关键技术点**: provider、policy、memory、capability 都通过接口注入，agent 核心不绑定具体模型服务。
4. **数据流向**: 输入被规范化为 `AgentWorkflowState`，workflow step 持续更新 state，最终由 `finalize` 生成 `AgentRunOutput`。
