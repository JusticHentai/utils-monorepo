# supportTextEncoder

判断当前运行环境是否可以直接使用 `TextEncoder`。

## 具体逻辑

<table>
  <thead>
    <tr>
      <th>步骤</th>
      <th>代码动作</th>
      <th>读取对象</th>
      <th>返回结果</th>
      <th>调用方影响</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>1</td>
      <td>
        执行 <code>typeof TextEncoder !== 'undefined'</code>
      </td>
      <td>
        全局作用域里的 <code>TextEncoder</code> 绑定
      </td>
      <td>
        存在时返回 <code>true</code>，不存在时返回 <code>false</code>
      </td>
      <td>
        <code>estimateBytes</code> 据此决定是否调用
        <code>new TextEncoder().encode(text)</code>。
      </td>
    </tr>
  </tbody>
</table>

## 分支行为

<table>
  <thead>
    <tr>
      <th>环境</th>
      <th>supportTextEncoder 返回值</th>
      <th>estimateBytes 后续行为</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>现代浏览器或支持全局 TextEncoder 的运行时</td>
      <td>
        <code>true</code>
      </td>
      <td>
        按 UTF-8 编码后的 <code>Uint8Array.length</code> 计算字节数。
      </td>
    </tr>
    <tr>
      <td>缺少 TextEncoder 的旧环境</td>
      <td>
        <code>false</code>
      </td>
      <td>
        降级为 <code>text.length</code>，ASCII 准确，中文和 emoji 会低估。
      </td>
    </tr>
  </tbody>
</table>
